# Paint Picker

Пипетка для моделистов. Открываешь фото, наводишься на нужное место и получаешь цвет, ближайшие к нему краски Vallejo Game Color и рецепт, как смешать этот цвет из красок, которые у тебя уже есть.

## Скачать

[**PaintPicker-Setup.exe**](https://github.com/LeoDex0/paint-picker/releases/latest/download/PaintPicker-Setup.exe) — установщик для Windows, около 98 МБ.

При первом запуске Windows покажет окно «Система Windows защитила ваш компьютер», потому что файл не подписан. Нажми «Подробнее», затем «Выполнить в любом случае».

Версия без установки лежит на [странице релизов](https://github.com/LeoDex0/paint-picker/releases/latest).

## Что умеет

- **Пипетка.** Фото можно перетащить в окно, вставить через Ctrl+V или выбрать файлом. Клик берёт цвет, колесо меняет масштаб, правая кнопка двигает фото. Размер пипетки настраивается, цвет в круге считается как среднее или как преобладающий.
- **Совпадения.** Список красок Game Color от самой похожей к менее похожим, с процентом совпадения. В каждой строке слева нужный цвет, справа краска.
- **Мои краски.** Отмечаешь, что есть на полке. Список сохраняется между запусками.
- **Рецепт.** Подбирает смесь из двух-трёх отмеченных красок: сколько частей каждой взять и какой цвет выйдет.

Цвет можно и просто вписать в поле HEX, без фото.

## Насколько этому верить

- Цвет на фото зависит от освещения и камеры. Снимай при дневном свете и бери средний тон, а не блик или тень.
- Процент показывает сходство с цифровым образцом краски. На модели оттенок ещё зависит от грунта и числа слоёв.
- Рецепт приблизительный: он считается по цвету образцов, настоящих данных о пигментах нет. Смешай пару капель на пробу и подправь на глаз.
- Металликов и смывок в базе нет: их не описать одним цветом.

## Запуск из исходников

Нужен Node.js 22 или новее.

```
npm install
npm start
```

## Сборка

```
npm run dist
```

В папке `dist` появятся `PaintPicker-Setup.exe` (установщик) и `PaintPicker-Portable.exe` (работает без установки, но каждый запуск распаковывается секунд пятнадцать).

## Откуда данные

- Цвета красок — [miniature-paints](https://github.com/Arcturus5404/miniature-paints), MIT. Список пересобирается командой `node scripts/build-paints.js путь/к/Vallejo.md`.
- Спектральные таблицы для смешивания — [spectral.js](https://github.com/rvanwijnen/spectral.js), MIT.

Тексты лицензий лежат в `THIRD-PARTY.md`.
